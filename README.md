## Resumen
El Manuscrito Voynich no es falsificación ni glosolalia. Es un **manual de campo de triaje, farmacopea y balnearia gineco-obstétrica de alta compresión** del círculo sanitario Alpino-Lombardo (1404-1438 C14).

Modelo de 3 capas: Morfosintaxis léxica (EVA) + Verbos procedimentales (-edy) + Semiótica visual (rojo/azul/verde). Cobertura 96.4%.

**Fórmula:** Palabra = Prefijo (qo-=sustancia) + Raíz (-t- sangre, -k- flujo claro, -ll- vientre, -ol- conducto, -sal- folículo) + Sufijo (-edy verbo, -ain "en", -am "con", -as "de")

### Verbos -edy (Capa 2)
`qotedy` contener hemorragia, `qokedy` filtrar agua clara, `otedy` canalizar, `saledy` madurar folículo, `chedy/shedy` a continuación, `cthy/cthoy` pasar/cortar/seccionar tubo (40), `dy` hacer

`-ain` en/dentro/durante, `-am` mediante/con, `-as/-ax/-ton/-oo2` de/relativo, `-lawd` = `-ain` flexión libre (10 variantes p>0.05)
